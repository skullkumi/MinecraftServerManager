# 変更履歴

## v1.1.0 (2026-11-15)
### 追加
- 友達用クライアントパックの作成 (Modrinth .mrpack / CurseForge形式ZIP / 通常ZIP)
- 不足している前提MODをModrinthで探して自動取得 (診断結果・MOD管理から。必須の前提MODも一緒に解決)
- タスクトレイ常駐 (画面を閉じてもサーバーを動かし続ける)・Windowsサインイン時の起動
- 初回起動ウィザード (かんたんセットアップ)
- 異常終了時の自動再起動 (回数制限付き)・スケジュール (定時再起動・起動/停止・定時バックアップ・予告)
- Discord Webhook通知
- Forge/NeoForge のクライアント専用MOD判定をクラス解析で強化 (実在MOD 53件で誤検出0件を確認)
- MODの更新チェック (Modrinth)・選択更新 (古いファイルは退避)
- 負荷モニター (CPU・メモリ・人数・TPS・MSPTのグラフ、7日分保存、CSV出力)
- playitサービスのログから公開側アドレス・転送先ポートの誤りを検出
- フォルダー版・インストーラー (Inno Setup) のビルド、コード署名 (証明書がある場合)、アプリの更新 (SHA-256検証)、GitHub Actions
- Purpur / Quilt サーバー
- UPnPによるポート開放 (任意)
- 差分バックアップ (変更されたファイルだけ保存)
- ダークテーマ・英語UI
- 伏せ表示 (IPアドレス・公開アドレス・ユーザー名を伏せる。既定でオン)
### 変更
- 画面を整理: 左のメニューを17項目から7項目 (ホーム / サーバー一覧 / コンソール / MOD / 友達を招待 / サーバー設定 / アプリ設定) にまとめ、関連する画面をタブにした
- サーバー一覧を複数サーバーの管理画面に: 一括起動・停止・再起動、メモリ・CPU・参加人数の一覧表示、ポート重複の自動回避、メモリ合計の確認、右クリックメニュー
- 機能を使う場所へ移動: 異常終了時の「原因を調べる」、参加人数からプレイヤー一覧へ、友達用パックを「友達を招待」に、MODパック/CurseForgeプロファイルからの追加を「MOD → ＋MODを追加」に
- MOD・プラグインが使えないサーバー (Vanilla) ではMODメニューを表示しない
- 画面上部のサーバー欄に稼働状態の印 (🟢⚪🔴) を表示
- 画面デザインを全面的に見直し (ダッシュボードの再設計、カード型レイアウト、どの画面からも起動/停止)
- 既定のポート番号は、ほかのプログラムが使用中のポートを避けて提案するように変更
### 修正
- CPU使用率が常に0%と表示される問題
- 同じ秒に作成したバックアップが上書きされる可能性があった問題

Minecraft Server Manager v1.1.0

【起動】
MinecraftServerManager.exe をダブルクリックしてください。
(インストール不要。Pythonなども不要です)

初回に「WindowsによってPCが保護されました」と出た場合は、
配布元を確認のうえ「詳細情報」→「実行」を押してください。

【はじめての方】
1. 「サーバー一覧 → ＋ 新しく作る」でサーバーを作ります。
2. ホームの「サーバーを起動」を押します。
3. Minecraftのマルチプレイで「localhost」に接続します。

最初に表示される「かんたんセットアップ」を使うと、質問に答えるだけで準備できます。
MODパックを使う場合は「サーバー一覧 → MODパックから作る」から、
友達を招待する場合は「友達を招待」から設定してください。
複数のサーバーは「サーバー一覧」でまとめて起動・停止できます。

【注意】
・サーバーの起動にはMinecraft EULAへの同意が必要です。
・サーバーの稼働中に画面を閉じると、タスクトレイに格納されサーバーは動き続けます。
  完全に終了するときはトレイのアイコンを右クリック →「終了」(サーバーは安全に停止します)。
・画面右上の「伏せ表示」がオンの間、IPアドレスやユーザー名を伏せて表示します (配信・画面共有向け)。
・元のMODパックやワールドは変更しません。設定変更前には自動でバックアップします。
・大切なワールドは、別の場所 (外付けディスクなど) にもバックアップしてください。
・クライアント専用MODの判定・MODエラーの診断は100%正確ではありません。

# Minecraft Server Manager v1.1.0

Minecraft Java版のサーバーを、**ボタン操作だけで**作成・管理・MOD導入・トラブル診断・友達の招待までできるWindows用アプリです。
CurseForgeやplayit.ggが入っていなくても使えます。

## 1. 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / Windows 11 (64bit) |
| メモリ | 8GB以上推奨 (MOD入りサーバーは16GB以上推奨) |
| ディスク | サーバー1台あたり 1～10GB程度 (MOD・ワールドの量による) |
| インターネット | サーバー本体・MOD・Javaのダウンロードに必要 |
| 必要なランタイム | **なし** (Pythonなどは不要。Javaが無い場合はアプリから導入できます) |

## 2. インストール・起動

配布物は3種類あります。どれも中身は同じです。

| ファイル | 特徴 |
|---|---|
| `MinecraftServerManager-Setup-v1.1.0.exe` (インストーラー) | スタートメニューに登録。管理者権限は不要。**おすすめ** (配布されている場合) |
| `MinecraftServerManager-v1.1.0-folder.zip` (フォルダー版) | 展開して `MinecraftServerManager.exe` を実行。起動が速い |
| `MinecraftServerManager-v1.1.0.zip` (ポータブル版) | EXEが1つだけ。USBメモリなどにも置ける。起動に数秒かかる |

- 初回に「WindowsによってPCが保護されました」と表示されることがあります。署名されていないアプリで表示される警告です。
  配布元を確認したうえで「詳細情報」→「実行」を押してください。
- サーバーがまだ無いときは、起動すると **かんたんセットアップ** が自動で開きます。

## 3. はじめてのサーバー作成 (かんたんセットアップ)

1. 「どのように遊びますか？」で、**MODなしで遊ぶ** / **MODパックを使う** / **MODサーバーを自分で作る** から選びます。
2. Minecraftのバージョン (遊ぶMinecraftと同じもの) を選び、EULAに同意します。
3. 友達の招待方法 (LAN限定 / playit.gg / 直接公開) を選んで「作成する」。必要なJavaが無ければ導入も案内されます。
4. ダッシュボードの大きな **「▶ サーバーを起動」** を押し、状態が「稼働中」になったら、
   Minecraftの「マルチプレイ」→「サーバーを追加」→ ダッシュボードの **「このPCから」** のアドレス (例: `localhost`) で参加します。

> 自分で細かく設定したい場合は、**「サーバー一覧 → ＋ 新しく作る」** から作成できます。
> サーバーの種類: Vanilla (公式) / Paper / Purpur (プラグイン) / Fabric / Quilt / Forge / NeoForge (MOD)

## 4. MODパックでサーバーを作る

### CurseForge・Modrinthのパック

1. **「サーバー一覧 → 📦 MODパックから作る」** で、CurseForgeのZIP・Modrinthの `.mrpack`・サーバーパックZIP・MODをまとめたZIPを選びます。
2. 「解析」で内容を確認し、「インポートを開始」。
3. MODごとにサーバーで使えるかを判定した確認画面が出ます。
   - **クライアント専用 (確定)**: サーバーには入れず、サーバー内の `.msm/excluded_client_mods` に保管します。
   - **クライアント専用の可能性 (要確認)**: チェックを入れたものだけサーバーに入れます。

> CurseForge形式のZIPにはMOD本体が入っていないため、自動取得にはCurseForge APIキー (アプリ設定) が必要です。
> キーが無くても処理は止まらず、「MOD → 手動ダウンロード補助」タブでブラウザからダウンロードして取り込めます
> (ダウンロードフォルダーを監視し、ハッシュ値で照合してから取り込みます。元のファイルは移動・削除しません)。

### MOD管理でできること

| ボタン | 内容 |
|---|---|
| ＋ MODを追加 | JARファイル・フォルダーから追加。**不足している前提MODをModrinthで探して自動で追加** もここから |
| 友達用パックを作成 | 参加する人がランチャーに読み込める、サーバーと同じMOD構成のパックを作成 (次項) |
| 更新を確認 | Modrinthで新しい版があるMODを一覧し、選んだものだけ更新 (古いファイルは退避) |
| 選択したMODを無効化 | 削除せず `disabled_mods` に退避 (「無効化・履歴」タブから戻せます) |

### 友達用パック (参加する人の準備)

MODサーバーに参加する人は、サーバーと同じMODが必要です。「友達を招待 → 友達用パックを作成」で次の形式から選べます。

| 形式 | 読み込み方 |
|---|---|
| Modrinth形式 (.mrpack) | Modrinth App / Prism Launcher / ATLauncher で「インポート」。MOD本体は含まず、ダウンロード先URLだけを記載 |
| CurseForge形式 (.zip) | CurseForgeアプリの「Import」。MOD本体を同梱 |
| 通常のZIP | modsフォルダーと導入手順。手動で導入 |

軽量化MODやミニマップなどのクライアント専用MODも含めます (サーバー専用MODは含めません)。
⚠ MOD本体を同梱する形式は、一緒に遊ぶ友達への個人的な共有にとどめてください (再配布が禁止されたMODがあります)。

## 5. 友達を招待する

**「友達を招待」** で方法を選びます。どれを使うかは自由です。

| 方法 | メリット | デメリット |
|---|---|---|
| **LAN限定** | 設定不要で最も安全 | 同じWi-Fi・同じルーターの人しか参加できない |
| **playit.gg** | ルーター設定不要。自宅のIPを知られない | playit.ggのアカウントと専用ソフトが必要。少し遅延が増えることがある |
| **直接公開 (ポート開放)** | 遅延が最小 | ルーター設定が必要。**自宅のグローバルIPを相手に教えることになる** |
| **VPN・その他のトンネル** | Tailscale / ZeroTier / Radmin VPN / ngrok など | サービスごとの設定が必要 |

- **playit.gg**: playitを公式サイトから導入し、playit.ggのWebでトンネルを作成して、表示された接続アドレスを入力します。
  「playitのログから接続先を探す」で、一度接続があった公開側のアドレスや、トンネルの転送先ポートの間違いを調べられます。
- **直接公開**: 画面の手順 (ファイアウォール・ルーター設定) に従ってください。ルーターがUPnPに対応していれば
  「UPnPでポートを開放」も使えます (任意。2時間ごとに延長し、サーバー停止時・アプリ終了時に自動で閉じます)。
- 接続アドレスはダッシュボードの **「参加する」** にまとめて表示され、「コピー」ボタンでコピーできます。
- ダッシュボードの **「全部起動」** は、サーバー → 公開用トンネル → ランチャーの順に起動します。

## 6. 画面の説明

左のメニューは7つです。各メニューの中はタブで切り替えます。画面上部の **サーバー欄** で操作するサーバーを選び、
**「▶ 起動 / ■ 停止」** でどの画面からでも起動・停止できます (欄の 🟢 は稼働中、⚪ は停止中、🔴 は異常終了)。

| メニュー | タブ | できること |
|---|---|---|
| 🏠 ホーム | 概要 / 負荷グラフ | 状態・起動/停止・参加人数・メモリ・CPU・TPS・参加アドレス・はじめの3ステップ。異常終了したときは「🩺 原因を調べる」が出ます |
| 🗂 サーバー一覧 | すべてのサーバー / ＋ 新しく作る / 📦 MODパックから作る | **複数サーバーの一括管理** (下記)・新規作成・MODパックからの作成・既存フォルダーの登録 |
| 🖥 コンソール | コンソール / プレイヤー / ログ / トラブル診断 | サーバーの出力・コマンド送信・キック/BAN/OP/ホワイトリスト (一覧を右クリック)・ログ・原因の推定と自動切り分け |
| 🧩 MOD (プラグイン) | MOD一覧 / 無効化・履歴 / 手動ダウンロード補助 | 追加・前提MODの自動取得・MODパックやCurseForgeプロファイルからの追加・更新・無効化。**MOD・プラグインに対応したサーバーのときだけ表示** |
| 🌐 友達を招待 | ― | 招待方法 (LAN / playit.gg / 直接公開 / その他)・接続アドレス・**友達用パック** (MODサーバーのとき) |
| ⚙ サーバー設定 | 基本設定 / ゲーム設定 / 直接編集 / プリセット / 自動化 / ワールド / バックアップ | メモリ・Java・server.properties・自動化・ワールドの切り替え・バックアップと復元 |
| 🔧 アプリ設定 | 一般 / Java / 外部連携 | 保存先・見た目・言語・通知・更新 / Javaの検出と導入 / CurseForge・Minecraftランチャー |

### 複数のサーバーを管理する (サーバー一覧)

- すべてのサーバーの状態・参加人数・メモリ・CPU・ポート・招待方法を一覧で表示します (3秒ごとに更新)。
- チェックを入れたサーバーを **まとめて起動・停止・再起動** できます。チェックが無いときは選んでいる行が対象です。
- 同時に起動するとき、**ポート番号が重なるサーバーは起動せず理由を表示** し、メモリの割り当て合計がPCの目安を超えるときは確認します。
- 行をダブルクリックするとそのサーバーのホームを開きます。右クリックでコンソール・設定・MOD・フォルダー・登録解除などを開けます。

### トラブル診断の見方

| 確信度 | 意味 |
|---|---|
| 確定 | ログにはっきり原因が出ている |
| 可能性：高 / 中 | 疑わしいが確証はない |
| 不明 | 原因を特定できなかった |

**診断結果はログからの推定です。実際の原因と異なる場合があります。**
「前提MODが不足」と診断された場合は「推奨対応を実行」でModrinthから前提MODを探して追加できます。
原因が分からないときは「自動切り分け」で、元の環境を変えずにテスト環境で原因のMODを絞り込めます。

### 差分バックアップ

前回のバックアップから変わったファイルだけを保存します (変わっていないファイルは前回分を共有します)。
大きなワールドでも容量と時間を節約でき、どの時点からでもそのまま復元できます。
定期・定時の自動バックアップは標準で差分方式です (バックアップ画面で切り替えられます)。

## 7. 自動化 (自動再起動・スケジュール・通知)

「サーバー設定 → 自動化」で設定します。

- **異常終了したら自動で再起動** (例: 10分以内に3回まで。超えたら止めて知らせます)
- **アプリの起動時にこのサーバーも起動**
- **スケジュール**: 曜日ごとの定時再起動・毎日の起動/停止・定時バックアップ。再起動・停止の5分前・1分前にゲーム内で予告します。
- **Discord通知** (アプリ設定でWebhook URLを設定): 起動・停止・異常終了・参加/退出・スケジュール実行・バックアップ失敗

アプリ設定の「動作」で、**画面を閉じてもタスクトレイに残ってサーバーを動かし続ける** (既定でオン) と、
**Windowsへのサインイン時にアプリを起動する** を設定できます。スケジュールはアプリが動いている間だけ実行されます。

## 8. 配信・画面共有するとき (伏せ表示)

画面右上の **「🙈 伏せ表示: オン」** (既定でオン) のとき、次の情報を伏せて表示します。

- グローバルIP・LANのIPアドレス・playitなどの公開アドレス (●●●● と表示。👁 ボタンで一時的に表示)
- パスに含まれるWindowsのユーザー名 (`%USERPROFILE%` と表示)
- コンソール・ログに出るプレイヤーの接続元IP

「コピー」ボタンは本当の値をコピーします。CurseForge APIキー・Discord Webhook URLは常に伏せ字です。
伏せ表示をオフにするときは確認が出ます。

## 9. 困ったときは

| 症状 | 対処 |
|---|---|
| 起動してすぐ止まる | 「コンソール → トラブル診断」→「診断を実行」 (ホームの「🩺 原因を調べる」でも開けます)。異常終了時は自動で案内します |
| 「Javaのバージョンが古すぎます」 | 「アプリ設定 → Java」で必要なJavaを導入。サーバー設定のJavaを「自動選択」にする |
| 「ポートがすでに使用されています」 | 同じポートの別サーバーを停止するか、サーバー設定でポート番号を変える |
| 「メモリ不足です」 | サーバー設定で最大メモリを増やす |
| 前提MODが足りない | 「トラブル診断」の推奨対応、または「MOD → ＋ MODを追加 → 不足している前提MODを探す」 |
| 友達が入れない | 公開方法・アドレスを確認。MODサーバーなら友達用パックを渡す |
| 設定を元に戻したい | 「サーバー設定 → バックアップ」→「直前の状態へ戻す」 |

## 10. 安全のための約束ごと

- 元のMODパック・ダウンロードしたファイル・ワールドを勝手に変更・削除しません (MODは `disabled_mods`、ワールドは `.msm` 内へ退避)。
- server.properties・config・MODを変更する前に自動でバックアップします。
- ダウンロードは公式の配布元を優先し、ハッシュ値で改ざん・破損を確認します。
- ダウンロードしたファイルを勝手に実行しません (例外: サーバー作成時のForge/NeoForge/Quiltの公式サーバーインストーラー、
  ユーザーが確認したアプリ更新)。
- Javaの導入で環境変数 (JAVA_HOME・PATH) や他のJavaを変更しません。
- APIキー・Webhook URLはWindowsの暗号化機能 (DPAPI) で暗号化して保存します。
- ルーター設定は、ユーザーがUPnPのボタンを押したときだけ変更します。

## 11. データの保存場所・アンインストール・更新

| 内容 | 場所 |
|---|---|
| アプリの設定・サーバー登録情報・負荷記録 | `%LOCALAPPDATA%\MinecraftServerManager\msm.db` |
| アプリが導入したJava | `%LOCALAPPDATA%\MinecraftServerManager\java\` |
| ログ・コンソール記録 | `%LOCALAPPDATA%\MinecraftServerManager\logs\` |
| サーバー (既定) / バックアップ (既定) | `%USERPROFILE%\MinecraftServers\` / `%USERPROFILE%\MinecraftServers\_backups\` |

- **アンインストール**: インストーラー版は「アプリと機能」から。ZIP版はフォルダーを削除。
  設定を消す場合は `%LOCALAPPDATA%\MinecraftServerManager` も削除してください。サーバーとバックアップは自動では削除されません。
- **更新**: アプリ設定の「アプリの更新」で、配布元 (GitHubリポジトリまたは更新情報URL) を設定すると、
  新しい版をSHA-256で検証してから更新できます (古いファイルは `.old` として残ります)。

## 12. できること・できないこと

- アプリを完全に終了するとサーバーも停止します (タスクトレイに格納中は動作し続けます)。
- CurseForgeの特定のプロファイルを外部から直接起動する公開された方法が無いため、CurseForgeはアプリの起動までを補助します。
- playit.ggのトンネル作成はplayit.ggのWebで行います。接続アドレスが自動取得できない場合は手入力してください。
- クライアント専用MODの判定は100%ではありません。判定不能・可能性のみのMODは勝手に除外せず、確認画面で選べます。
- 英語モード (English) ではメニュー・ボタン・見出し・設定の説明を英語で表示します。長い説明文や診断メッセージの一部は日本語のままです。

詳しい対応状況は `FEATURES.md` を参照してください。
